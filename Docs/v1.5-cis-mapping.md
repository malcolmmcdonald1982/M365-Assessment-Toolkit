## Profile Model (v7.0.0)

| Profile | Meaning |
|---|---|
| E3 L1 | Baseline security — any M365 E3/Business tenant |
| E3 L2 | Enhanced — E3, may reduce some functionality |
| E5 L1 | Extends E3 L1 — requires E5/Defender/Entra P2 licences |
| E5 L2 | Most comprehensive — E5, may reduce functionality |
