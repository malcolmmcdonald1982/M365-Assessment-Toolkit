⚙️
PowerShell modules requiredThe first scan installs required modules automatically (ExchangeOnlineManagement, Microsoft.Graph, MicrosoftTeams). This takes 3–5 min on first run — subsequent scans are fast. Requires internet access.
⚠️
If a module fails mid-scanThe scan continues — failed modules are skipped and logged. Check the Run Log tab for details. Common causes: MFA prompt timeout, Conditional Access blocking the script account, or insufficient role. Re-run the scan after resolving the issue.

Assessment Authentication
💡 You can assess any tenant — your own or a client's. Enter the client's Tenant ID below and sign in with an account that has read access to their environment.
Minimum role required: Global Reader covers most modules. Exchange also accepts Exchange Administrator.
Exchange, Teams & SharePoint modules always use interactive login even in App Registration mode.
Client creates an App Registration in Entra ID. Read-only permissions only. Client can revoke access after the assessment.
Exchange, Teams & SharePoint will still prompt interactively — these workloads do not support app-only auth in the same way.
Uses a certificate installed in the local Windows certificate store. No secret stored in the UI — more secure for repeat assessments.
The certificate must already be installed under Current User\My or Local Machine\My.
Exchange, Teams & SharePoint will still prompt interactively — certificate auth applies to Graph-based modules only.
