## Planned Features

### 1. Environment Selector (GCC / GCCH / DoD)
**Why:** Rajak asked about GCCH support in comments. Likely not the only one.
**What it means:**
- Add a dropdown in the UI: Commercial / GCC / GCCH / DoD
- Switch Graph endpoint: graph.microsoft.com → graph.microsoft.us (GCCH/DoD)
- Switch login endpoint: login.microsoftonline.com → login.microsoftonline.us
- Exchange/Teams/SharePoint interactive auth already handles this via the login popup
- Scope limited to Graph-based modules first (Identity, Security, Intune)

**Effort:** Medium — affects auth flow and all PowerShell scripts
**Risk:** Cannot test without a GCCH tenant — need a volunteer tester from the community

---

### 2. Certificate-Based Authentication
**Why:** Client secret in the UI is a security concern for some users. Certificate auth is cleaner for repeat assessments.
**What it means:**
- Add a third auth option: Certificate (alongside Interactive and App Reg)
- User provides Tenant ID, Client ID, Certificate Thumbprint
- Certificate must already be installed in the local cert store
- PowerShell scripts use Connect-MgGraph -CertificateThumbprint

**Effort:** Medium
**Risk:** Low — certificate auth is well documented in Microsoft Graph PowerShell
